# Math-Belgium

Site de chapitres de cours de mathématiques (FWB, 4e/5e/6e), avec liens directs vers les
générateurs d'exercices interactifs de [plateforme-maths](https://plateforme-maths.vercel.app).

Voir [`CLAUDE.md`](./CLAUDE.md) pour l'architecture (gabarit unique `ChapterPage` + contenu en
données) et les conventions du projet.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
